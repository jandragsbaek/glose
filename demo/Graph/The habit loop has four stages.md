Clear splits every habit into four steps: cue, craving, response and reward. The cue triggers a craving, the craving drives a response, and the reward satisfies the craving and teaches the brain to repeat the loop. He builds the whole book on this: the four laws (make it obvious, attractive, easy, satisfying) each target one stage.

Once a loop is learned, it runs without much thought. That sounds a lot like Kahneman's fast, automatic mode: [[System 1 is fast and System 2 is slow]]. A habit is a task moved from System 2 to System 1.

The model is a simplification, and Clear says it builds on earlier work (cue, routine, reward). But it is a good way to see where to intervene: [[Implementation intentions make the cue obvious]], [[Temptation bundling pairs a want with a need]], [[The two-minute rule makes starting easy]].
